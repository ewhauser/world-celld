# Security policy

## Supported versions

Security fixes are provided for the latest published version. Before 1.0, a
security fix may include an incompatible API or storage change when that is the
safest resolution.

## Reporting a vulnerability

Please use a [private GitHub security advisory](https://github.com/ewhauser/world-celld/security/advisories/new).
Do not open a public issue for a suspected vulnerability.

Include the affected version, impact, reproduction details, and any suggested
mitigation. You should receive an acknowledgment within seven days. Please do
not disclose the issue publicly until a fix and coordinated disclosure plan are
available.
